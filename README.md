# ARIA for Windows

ARIA is an assistant that works on your computer rather than in a browser tab. Say or type what you want, and ARIA shows you exactly what it is about to do, then does it once you approve.

## Download

**[Download ARIA for Windows](https://github.com/ekendirichukwu/aria-download/releases/latest/download/ARIA-Setup.exe)** (230 MB, Windows 10 or 11, 64-bit)

This is an early build.

## Setting it up

1. Run the installer. It is not code-signed yet, so Windows will probably say the publisher is unrecognised. Choose **More info**, then **Run anyway**. If your browser asks whether to keep the file, choose **Keep**.
2. ARIA starts as a small round icon in the corner of the screen. Click it, or press **Ctrl + Alt + A**, to open it.
3. ARIA uses Google's Gemini to understand everyday phrasing and to write documents. Create a free key with a Google account at [aistudio.google.com/api-keys](https://aistudio.google.com/api-keys) and paste it in when ARIA asks. It is stored encrypted on your computer.
4. Press the microphone in ARIA's command box and speak, or type there instead. Speech is turned into text on your own computer.
5. Optional: press **PHONE** on ARIA and scan the code with your phone's camera to send ARIA commands from anywhere.

## Updating

Download from the same link and install over the old version. Your key, calendar and settings stay.
